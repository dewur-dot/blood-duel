# 피의 결투

Claude에서 만든 v33 `index.html`을 바탕으로, 친구가 카카오톡 링크에서 결투하거나 도주한 결과를 두 기기가 공유하도록 연결한 버전입니다.

## 사용 방법

1. 각자 게임에서 전사를 만듭니다.
2. 도전자가 **결투장 던지기**에서 링크를 카카오톡으로 보냅니다.
3. 친구가 링크를 열고 **덤벼라** 또는 **등을 보인다**를 선택합니다.
4. 수락하면 친구에게 바로 결투가 재생됩니다. 도전자는 게임을 다시 열거나 해당 탭으로 돌아오면 같은 기록을 재생합니다.
5. 패자의 전사는 각자의 기기에 사망 처리됩니다.

결투 기록은 Firebase 프로젝트 `blood-duel`의 Cloud Firestore에 저장됩니다. 전사와 묘지 등 개인 진행 상황은 기존 게임처럼 해당 브라우저의 저장 공간에 보관됩니다. 브라우저 데이터를 삭제하거나 다른 기기로 옮기면 개인 전사가 자동 복원되지 않습니다. 링크를 가진 사람이 결투 기록을 읽을 수 있으며, 순위나 보상을 위한 부정행위 방지 기능은 없습니다.

## 배포

GitHub의 `dewur-dot` 계정에 **새 공개 저장소 `blood-duel`**을 만들고 이 폴더의 파일을 저장소 최상위에 올립니다. GitHub Pages의 배포 원본을 `main` 브랜치의 `/ (root)`로 지정합니다. 예상 주소는 `https://dewur-dot.github.io/blood-duel/`입니다. Firebase 프로젝트는 별도로 설정되어 있으며, 웹 앱 구성은 `firebase-config.js`, 데이터베이스 규칙은 `firestore.rules`에 들어 있습니다.

GitHub Pages 배포 주소에서 두 브라우저 또는 두 기기로 수락, 도주, 재접속 흐름을 확인하세요. 카카오톡 공유 버튼이 없는 브라우저에서는 링크가 복사됩니다.
